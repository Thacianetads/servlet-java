# 🏥 Sistema de Agendamento de Consultas (Java Servlets)

> Sistema web desenvolvido em Java EE utilizando Servlets e JSP, focado no gerenciamento e agendamento de consultas médicas. 

---

## 🚀 Tecnologias Utilizadas

As seguintes tecnologias e ferramentas foram usadas na construção do projeto:

* **Java**: Linguagem principal de programação.
* **Java EE (Jakarta EE APIs)**: Especificações para aplicações corporativas (Servlets, JSP, JDBC).
* **Apache Tomcat**: Servidor web e servlet container.
* **HTML e CSS**: Interface de usuário responsiva.

---

## 📋 Pré-requisitos

Antes de iniciar, certifique-se de ter instalado em sua máquina:
* [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/)
* [Apache Tomcat](https://tomcat.apache.org/)

---
